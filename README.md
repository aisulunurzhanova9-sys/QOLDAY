# СВЯЗЬ — видеодиспетчерская служба

Flutter-приложение для глухих и слабослышащих людей: видеозвонок с
сурдопереводчиком, текстовый чат с диспетчером, экстренный вызов 112,
контакты, история и настройки. Все оповещения визуальные (вспышка экрана
+ вибрация), без опоры на звук.

## Структура проекта

```
lib/
  main.dart                     — точка входа, нижняя навигация
  theme/app_theme.dart          — цвета, шрифты (Manrope + Inter + JetBrains Mono)
  widgets/shared_widgets.dart   — переиспользуемые виджеты (карточки, плашки, списки)
  screens/
    home_screen.dart            — главная: вызов переводчика, статус сети, SOS
    chat_screen.dart            — текстовый чат с диспетчером
    contacts_screen.dart        — избранные контакты и службы
    history_screen.dart         — журнал вызовов
    settings_screen.dart        — сеть, оповещения, размер субтитров
    call_screen.dart            — активный видеозвонок с живыми субтитрами
    incoming_call_screen.dart   — входящий вызов: вспышка + вибрация вместо звука
```

## Запуск

Понадобится установленный Flutter SDK (проверено на канале stable, Dart ≥3.3):

```bash
flutter pub get
flutter run
```

Для сборки:

```bash
flutter build apk        # Android
flutter build ios        # iOS (нужен macOS + Xcode)
```

## Что уже работает в прототипе

- Переключение вкладок: Главная / Контакты / История / Настройки
- Демонстрация входящего вызова: пульсирующая вспышка + `HapticFeedback`
  (вибрация) вместо звукового рингтона
- Экран звонка с таймером и циклически сменяющимися субтитрами (демо-данные)
- Переключатели приоритета сети (Wi-Fi / мобильные данные), автопереключения,
  экономного режима видео, визуальных оповещений
- Ползунок размера субтитров с live-превью

## Что нужно доделать для продакшена

Это UI-прототип с демонстрационными данными. Для реального продукта
потребуется:

1. **Видеосвязь** — интеграция WebRTC (например, пакеты `flutter_webrtc`
   или сервис вроде Twilio/Agora) для реального видеопотока с переводчиком.
2. **Бэкенд диспетчерской** — очередь вызовов, распределение переводчиков,
   API для истории и контактов (сейчас данные захардкожены в виджетах).
3. **Push-уведомления о входящем вызове**, когда приложение свёрнуто
   (Firebase Cloud Messaging / APNs) — с той же логикой «вспышка + вибрация».
4. **Автораспознавание речи → субтитры** (сейчас субтитры — заглушка из
   фиксированного списка фраз).
5. **Реальный мониторинг сети** (пакет `connectivity_plus`) для честного
   определения Wi-Fi/мобильных данных и автопереключения.
6. Тестирование с реальными пользователями сервиса (глухими и
   слабослышащими) — особенно контраст, размер целей нажатия и логику
   визуальных оповещений.
